# PRD – AI 할 일 관리 웹 서비스

## 1. 개요
본 문서는 AI 기반 할 일 관리 웹 서비스의 제품 요구사항(Product Requirements Document)을 정의한다. 본 서비스는 사용자의 할 일을 효율적으로 관리하고, AI를 활용해 할 일 생성, 요약, 분석 기능을 제공하는 것을 목표로 한다.

---

## 2. 제품 목표
- 사용자가 직관적으로 할 일을 관리할 수 있는 웹 서비스 제공
- AI를 활용해 할 일 입력 및 관리에 소요되는 시간을 최소화
- 개인 및 업무 생산성 향상

---

## 3. 핵심 사용자 시나리오
1. 사용자는 회원가입 후 로그인한다.
2. 할 일을 직접 입력하거나 자연어로 입력해 AI가 자동 생성한다.
3. 할 일을 검색, 필터, 정렬하며 관리한다.
4. AI 요약을 통해 오늘/이번 주의 업무 현황을 한눈에 파악한다.

---

## 4. 주요 기능 요구사항

### 4.1 사용자 인증
- 이메일/비밀번호 기반 로그인 및 회원가입
- Supabase Auth 사용
- 로그인 상태 유지 및 로그아웃 지원

---

### 4.2 할 일 관리 (CRUD)
- 할 일 생성(Create)
- 할 일 조회(Read)
- 할 일 수정(Update)
- 할 일 삭제(Delete)

**할 일 데이터 필드**
- title: 제목
- description: 설명
- created_date: 생성일
- due_date: 마감일
- priority: 우선순위 (high / medium / low)
- category: 카테고리 (업무 / 개인 / 학습 등)
- completed: 완료 여부 (boolean)

---

### 4.3 검색, 필터, 정렬

**검색**
- 제목 및 설명 기준 검색

**필터**
- 우선순위 (높음 / 중간 / 낮음)
- 카테고리 (업무 / 개인 / 학습 등)
- 진행 상태 (진행 중 / 완료 / 지연)

**정렬**
- 우선순위순
- 마감일순
- 생성일순

---

### 4.4 AI 할 일 생성
- 사용자가 자연어로 입력한 문장을 분석해 구조화된 할 일 데이터로 변환
- Google Gemini API (AI SDK) 사용

**입력 예시**
- "내일 오전 10시에 팀 회의 준비"

**출력 예시**
```json
{
  "title": "팀 회의 준비",
  "description": "내일 오전 10시에 있을 팀 회의를 위해 자료 작성하기",
  "created_date": "YYYY-MM-DD, HH:MM",
  "due_date": "YYYY-MM-DD, 10:00",
  "priority": "high",
  "category": "업무",
  "completed": false
}
```

---

### 4.5 AI 요약 및 분석
- 사용자의 할 일을 AI가 분석해 요약 정보 제공

**일일 요약**
- 오늘 해야 할 작업 목록 요약

**주간 요약**
- 이번 주 전체 작업 진행 상황
- 완료율 분석

---

## 5. 화면 구성

### 5.1 로그인 / 회원가입 화면
- 사용자 인증 및 계정 관리

### 5.2 할 일 관리 메인 화면
- 할 일 목록 표시
- 할 일 추가 및 수정
- 검색, 필터, 정렬 UI
- AI 요약 및 분석 결과 표시

### 5.3 AI 통계 및 분석 화면
- 작업 추가 추이
- 완료율 시각화
- 카테고리별 통계 차트

---

## 6. 기술 스택
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Shadcn/ui
- Supabase (Auth, Database)
- AI SDK (Google Gemini API)

---

## 7. 데이터 구조

### 7.1 users 테이블
- Supabase Auth와 연동
- 사용자 기본 정보 관리

### 7.2 todos 테이블
- 사용자별 할 일 데이터 관리
- users 테이블과 관계 설정 (1:N)

---

## 8. 비기능 요구사항
- 반응형 웹 디자인 (모바일/데스크톱 지원)
- 로딩, 빈 상태, 오류 상태 UI 제공
- 사용자에게는 한글 오류 메시지 제공
- 개발 환경에서는 상세 로그 출력

---

## 9. 주의 사항

- Supabase 프로젝트 환경변수는 `.env.local` 파일에 저장한다.
- AI API 키는 절대 클라이언트 코드에 직접 노출하지 않으며, 서버(API Route)에서만 사용한다.
- 개발 시 `npm run dev` 명령어로 개발 서버를 실행한다.

---

## 10. 향후 확장 고려 사항
- 알림 기능 (이메일 / 푸시)
- 팀 단위 할 일 공유
- 캘린더 연동

---

## 11. 성공 지표 (KPI)
- 월간 활성 사용자 수(MAU)
- 일일 할 일 생성 수
- AI 할 일 생성 기능 사용 비율
- 사용자 재방문율
